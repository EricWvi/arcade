本站数据来自游戏代码，对应站内的造梦西游 1（SAV 改版，掉宝率提升到原版的 125%）。

- [boss 掉落](bosses.md)：每一关 boss 掉什么、掉率多少，以及牛魔王和龙王的必得法宝
- [装备图鉴](equipment.md)：所有 boss 装备的属性
- [宝箱](treasure-chest.md)：随机刷出的宝箱，掉落属性随关卡提升的传说装备
- [战功](zhangong.md)：怎么获得战功、能兑换什么
- [战斗数值](combat.md)：生命、魔法、攻击、防御、暴击、闪避怎么算，以及各 boss 的防御和血量

## 掉落的通用规则

- 每只 boss 最多掉一件装备。
- 掉落列表里有多件装备时，排在两端的装备概率只有中间的一半。例如 3 件装备的概率是 25% / 50% / 25%。
- 带范围的属性（例如“攻击 30–40”）在你**捡起来的那一刻**才随机决定。
- 背包最多 25 件，满了就捡不起来，先清背包再去打 boss。
- boss 装备掉在地上不会消失；宝箱掉的装备约 80 秒后会消失。
